# Pixelize

Pixelize is an open-source Android customization toolkit designed to help users move closer to a clean, Google-first Android experience without rooting, unlocking the bootloader, or compromising device stability.

## Goals

- Safe and reversible customization
- Preserve OTA updates
- Preserve banking and enterprise app compatibility
- Eliminate unnecessary OEM software where possible
- Generate detailed device reports
